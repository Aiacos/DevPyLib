Adv_Face

Builds the AdvancedSkeleton facial rig (joint based, fitted on the mesh) as an Arise node.

Before building

The face must be fitted first: the scene needs the FaceFitSkeleton node created by the face fitting UI of the facial_rig package (points and vertex loops selected on the face mesh). This node has no Arise guides.

Attributes

  • Geometry: face mesh, head joint, eyes, teeth, tongue. Leave a field empty to keep the value stored by the fitting.
  • Options: Eye Base, Eye Socket, Long Snout, Phonemes, Emotions, ARKit.

Connections

  • Head Input (driven): the head the face follows.
  • Face Output (driver): root of the face rig.

Status

Skeleton version. The rig is built with AdvancedSkeleton names and then renamed to the Arise convention; for now the rename covers the jaw and teeth only.
