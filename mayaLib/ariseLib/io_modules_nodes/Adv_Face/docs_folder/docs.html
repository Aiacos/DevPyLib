Adv_Face

Builds the AdvancedSkeleton facial rig (joint based, fitted on the mesh) as an Arise node.

Before building

The face must be fitted first: the scene needs the FaceFitSkeleton node created by the face fitting UI of the facial_rig package (points and vertex loops selected on the face mesh). This node has no Arise guides: press Face Fitting at the top of the node's attributes to open that window and select the vertices and edge loops of eyelids, lips, nose and cheeks.

Attributes

  • Geometry: face mesh, head joint, mask, all head meshes, eyes, teeth, tongue, eyebrow, eyelash, extras. Leave a field empty to keep the value stored by the fitting.
  • Rig: Rig Type, Include, Lip Ctrls, Non Symmetrical, Simpler Eye Lid, Eye Base, Eye Socket, Cyclops, Long Snout, Lip To Nose Vertices.
  • Shapes: Phonemes, Emotions, ARKit, SnapChat.
  • Skinning: Game Engine, Multi Skin Clusters, Use Max Influences, Max Influences, Roblox Head, Legacy Joint Orient.
  • Scripts: Pre Rebuild Script.
  • Post Build: Delta Mush (smoothing deformer on the face), Head Squash (squash and stretch controllers for the whole head) and Wrinkle Map (wrinkle curves in their starting place plus the bump map driven by the controllers; the images are written to the images/WrinkleMaps folder of the Maya project). Off by default; they are rebuilt with the rig.

These are the options of the AdvancedSkeleton Face panel. A new node starts from the values stored by the fitting; after that the node's values are written to the fitting at every build. Multi Skin Clusters and Roblox Head have no effect yet. Rig Type BlendShapes or Mixed converts the joint-driven face to blendShapes at the end of the build (Mixed keeps the joints).

Several faces in one scene

Each Adv_Face node is one face. Everything the build creates is renamed with the node name as prefix (face_M_jaw_ctrl, face_L_upper_lid_...), so a character with two heads needs two nodes with different names. Only one fitting is editable at a time: pressing Face Fitting on a node brings its fitting back and puts the other one aside.

Leaving Build mode

The face rig is deleted, the skin weights of the face joints go back to the head joint and the fitting stays in the scene, so the node can be built again.

Connections

  • Face Output (driver): follows the root joint of the face, that is the head.
  • Jaw Output (driver): follows the jaw joint (not available with Rig Type BlendShapes).
  • Head Input (driven): no effect yet, the face follows the joint set in Head Joint.

Inside Arise

The controllers and the skinning joints of the face are tagged like Arise's own, so "select the controllers of this node" and the skinning joints selection include them. The rig lives under the group of this node in rig_root_grp; only the fitting stays in FaceGroup. With Keep Skin Weights (Skinning section, on by default) the skin weights of the face are stored when leaving Build mode and applied again at the next build, so hand-painted corrections are kept. They are dropped if the mesh or the face joints changed.

Status

Skeleton version, tried in Arise 1.15 on the AdvancedSkeleton "chubby" demo. The controllers are created by the build, so Arise's shape, scale and colour tools for declared controllers do not apply to them. The rig is built with AdvancedSkeleton names and then renamed to the Arise convention with the node name as prefix. AdvancedSkeleton's own tools (selector, picker) do not recognise the renamed rig.
